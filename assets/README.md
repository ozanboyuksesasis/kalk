# Assets Klasörü

Bu klasörde uygulama için gerekli görseller bulunmalıdır.

## Gerekli Dosyalar

1. **icon.png** (1024x1024 px)
   - Uygulama ikonu
   - Şeffaf arka plan önerilir

2. **splash.png** (1284x2778 px veya benzer oran)
   - Açılış ekranı görseli
   - Arka plan rengi: #ffffff

3. **adaptive-icon.png** (1024x1024 px)
   - Android adaptive icon
   - Arka plan rengi: #ffffff

4. **favicon.png** (48x48 px)
   - Web için favicon

## Geçici Çözüm

Eğer bu dosyalar yoksa, Expo otomatik olarak placeholder görseller oluşturacaktır. 
Ancak production için bu görselleri eklemeniz önerilir.

## Görsel Oluşturma

Basit görseller oluşturmak için:
- [Canva](https://www.canva.com/)
- [Figma](https://www.figma.com/)
- [GIMP](https://www.gimp.org/) (ücretsiz)

gibi araçları kullanabilirsiniz.
